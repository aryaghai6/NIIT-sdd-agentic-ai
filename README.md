## About

An interactive overview of NIIT StackRoute's **Spec-Driven Development (SDD) for Agentic AI** program for non-technical roles.

The program teaches Business Analysts, Project Managers and Program Managers to use the **specification as the shared control layer for Agentic AI**. Participants define the business outcome, workflow, context, guardrails, acceptance criteria, human oversight and delivery evidence before engineering begins. No coding is required.

## Program at a glance

## What the page covers

1. **Overview:** the program proposition, why SDD matters for Agentic AI, and a summary of all journeys.
2. **SDD Lifecycle:** the 8-stage lifecycle and the BA, PM and Program Manager accountabilities.
3. **Shared Language:** the 8 SDD elements in plain English.
4. **Shared Foundation:** two 3-hour workshops common to all personas.
5. **Scenario Bank:** five real-world agentic scenarios used across the journeys.
6. **Business Analyst journey:** curriculum, deliverables and specification mapping.
7. **Project Manager journey:** curriculum, deliverables and delivery-control mapping.
8. **Program Manager journey:** curriculum, deliverables and portfolio-governance mapping.
9. **Integrated Simulation:** Project Risk Sentinel, one case across all three roles.
10. **Artefact Stack:** who creates, uses and governs each artefact.
11. **Assessment & Credentials:** the five assessment layers and recommended certificates.
